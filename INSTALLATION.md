# Инструкция по установке и настройке автозапуска утилиты на Keenetic

Эта инструкция описывает, как перенести скомпилированный бинарный файл `keenetic-diag-util` на роутер **Keenetic Speedster (KN-3012)**, выдать права на исполнение и настроить его автоматический запуск как системной службы через среду **Entware**.

---

## 📋 Предварительные требования

1. На роутере должен быть установлен и настроен пакетный менеджер **Entware**.
   * *Инструкция по установке Entware доступна на официальном сайте поддержки Keenetic.*
2. Должен быть настроен доступ к роутеру по протоколу **SSH** (обычно порт 22 или 2222).
3. Компьютер (WSL/Linux/Windows) и роутер должны находиться в одной локальной сети.

---

## 🚀 Пошаговый процесс установки

### Шаг 1. Перенос бинарного файла на роутер

Скомпилированный файл необходимо скопировать в системную директорию исполняемых файлов Entware (`/opt/bin/`).

Откройте терминал на вашем компьютере (WSL, Linux, macOS или PowerShell в Windows) и выполните команду **SCP** (замените `192.168.1.1` на реальный IP-адрес вашего роутера):

```bash
scp -P 22 keenetic-diag-util root@192.168.1.1:/opt/bin/
```
*Если SSH-сервер Entware настроен на нестандартный порт, измените значение флага `-P 22` (например, на `-P 2222`).*

---

### Шаг 2. Настройка прав выполнения

1. Подключитесь к роутеру по протоколу SSH из вашего терминала:
   ```bash
   ssh -p 22 root@192.168.1.1
   ```
2. Разрешите запуск перенесенного бинарного файла в операционной системе Keenetic:
   ```bash
   chmod +x /opt/bin/keenetic-diag-util
   ```

---

### Шаг 3. Установка системных зависимостей

Для того чтобы вкладка **«Тест скорости»** могла выполнять реальные замеры пропускной способности интернет-канала, обновите пакетную базу Entware и установите официальную консольную утилиту `speedtest-cli`:

```bash
opkg update
opkg install speedtest-cli
```
*Утилиты `ping`, `uptime` и `ndmq` (для сбора данных WireGuard и модели устройства) уже встроены в KeeneticOS по умолчанию, для них ничего дополнительно устанавливать не нужно.*

---

### Шаг 4. Настройка автоматического запуска приложения

Чтобы утилита поднималась в память самостоятельно при каждом включении или перезагрузке роутера, необходимо создать скрипт инициализации в системной папке автозапуска Entware (`/opt/etc/init.d/`).

1. Создайте новый файл инициализации, выполнив в SSH-консоли роутера следующую команду:
   ```bash
   cat << 'EOF' > /opt/etc/init.d/S99keenetic-diag
   #!/bin/sh

   ENABLED=yes
   PROG=/opt/bin/keenetic-diag-util
   ARGS=""
   PREARGS=""
   DESC="Keenetic Diagnostic Web Utility"

   . /opt/etc/init.d/rc.func
   EOF
   ```
2. Сделайте созданный скрипт автозапуска исполняемым:
   ```bash
   chmod +x /opt/etc/init.d/S99keenetic-diag
   ```

---

## 🔄 Управление службой (Запуск / Остановка / Перезапуск)

После выполнения шагов выше вы можете управлять утилитой как стандартной системной службой Linux с помощью созданного скрипта:

* **Запустить утилиту прямо сейчас:**
  ```bash
  /opt/etc/init.d/S99keenetic-diag start
  ```
* **Остановить утилиту:**
  ```bash
  /opt/etc/init.d/S99keenetic-diag stop
  ```
* **Перезапустить службу:**
  ```bash
  /opt/etc/init.d/S99keenetic-diag restart
  ```
* **Проверить, запущена ли утилита в системе:**
  ```bash
  ps | grep keenetic-diag-util
  ```

---

## 🌐 Доступ к веб-интерфейсу

1. Откройте любой веб-браузер на устройстве, подключенном к сети роутера.
2. Перейдите по адресу: **`http://<IP-АДРЕС_РОУТЕРА>:8080`** (например, `http://192.168.1.1:8080`).
3. Для входа введите стандартные реквизиты:
   * **Логин:** `admin`
   * **Пароль:** `admin`
